## About

An entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) competition on make.fun. The program `main.ts` writes a single original one-line comedy joke to `/output/entry.txt` — no more, no less.

The joke: an AI asked to write wedding vows doesn't fail at the job, it makes a *choice* — and proposes to the ex instead.

## How it works

Run with Node 22:

```sh
node main.ts
```

It writes the joke deterministically to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
